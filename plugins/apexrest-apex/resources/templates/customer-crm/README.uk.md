# CRM клієнтів

[English](README.md) | Українська

Справжнє доповнення APEXlang до згенерованого Oracle стартового застосунку: звіт клієнтів (сторінка 10), дашборд (20), модальна форма (80), серверний пакет/тригер валідації, незмінна міграція таблиці, тести utPLSQL та автентифіковані браузерні CRUD з унікальними синтетичними записами. Типова автентифікація зберігається; налаштуйте окремий тестовий обліковий запис через дозволене адміністрування APEX. Паролів чи ORDS endpoint немає.

`project init ./crm --template customer-crm` генерує свіжі метадані Oracle й застосовує перевірене доповнення. Локальна компіляція SQLcl пройшла на 26.1.2 з MMD 26.1.0+3102. Розгортання на живу ціль, тестові селектори й результати SQL ще потребують інтеграційних доказів. Обов’язкові набори — SQL та E2E. Налаштуйте середовище й дозволені test grants, забезпечте utPLSQL для SQL-набору, потім автентифікуйтеся інтерактивно. Службові таблиці потрібні лише для явно вибраної координації БД; локальна координація є типовою.
