# Графіка документації

[English](README.md) | Українська

Наданий власником символ APEXREST з олівцем і лінійкою походить із `APEXREST-logo/apex rgb.svg`. Оригінал залишається незмінним у папці власника. Копії для відображення містять лише символ: контури літер видалено, фонової фігури немає. Вихідну геометрію символу й кольори збережено; квадратний viewBox зменшує порожні поля монтажної області, а доступний заголовок ідентифікує зображення.

[apexrest-logo.svg](apexrest-logo.svg) спільний для обох мов README, покажчика документації та всіх шапок сайту. [Логотип плагіна](../../plugins/apexrest-apex/assets/apexrest-logo.svg) та [іконка поля запиту](../../plugins/apexrest-apex/assets/apexrest-icon.svg) побайтово ідентичні йому. Метадані плагіна посилаються на прозорі SVG через `interface.composerIcon`, `interface.logo` та `interface.logoDark`. Збірки сайту й нативного пакета включають відповідні ресурси. Окремий стиль лого на сайті зберігає прозорість без тла й рамки.

Наведені нижче англійські й українські SVG-діаграми підтримуються безпосередньо в репозиторії; українські назви файлів закінчуються на `.uk.svg`. Вони використовують нативні векторні форми й системні шрифти без скриптів, зовнішніх ресурсів чи вбудованого HTML. Кожна діаграма має доступні заголовок і опис та `viewBox` для пропорційного масштабування.

[ords-codex-cloud.png](ords-codex-cloud.png) — створена ШІ на запит власника інфографіка APEXREST для анонсу ORDS/Cloud від 19 вересня 2026 року. Обидві мовні версії README використовують спільну англомовну графіку з локалізованим альтернативним текстом і повним текстовим поясненням. Вона ілюструє з’єднання CLI й запропонований процес команди агентів у Cloud; це не скріншот продукту й не доказ хмарного виконання. Обліковий запис і URL у прикладі є шаблонами.

Чотири файли `panel-*.jpg` — неретушовані кадри видимої області 872 × 683, зняті зі справжньої встановленої панелі у вбудованому браузері Codex 17 вересня 2026 року. Вони показують імена агентів, рев’ю менеджера та QA, налаштування SQLcl/команди й стан операцій ізольованого локального завдання з кодом. Для кадрування використано прокручування без зміни записаних результатів; локальної URL з ключем доступу чи облікових даних немає. Хеші та межі доказів наведено в [маніфесті знімків](../evidence/agent-workflow-documentation.json).

Зображення покемонів на скріншотах походять із локального комплекту [спрайтів PokeAPI](../../packages/panel/assets/sources.json). До них застосовується [оригінальне повідомлення про права](../../packages/panel/assets/LICENCE.txt); ліцензія коду репозиторію не змінює ліцензування зображень покемонів.
