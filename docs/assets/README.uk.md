# Графіка документації

[English](README.md) | Українська

Наданий власником знак APEXREST з олівцем і лінійкою походить із `APEXREST-logo/apex rgb.svg` та `APEXREST-logo/apex rgb line.svg`. Вихідні файли залишаються незмінними в папці власника. Копії для відображення мають зменшені порожні поля монтажної області, доступні заголовки й біле тло для контрасту; вихідні контури, напис і кольори збережено.

[apexrest-logo.svg](apexrest-logo.svg) використовується в обох мовах README, покажчику документації та відомостях плагіна. [apexrest-wordmark.svg](apexrest-wordmark.svg) — горизонтальний варіант для шапки сайту. [Логотип плагіна](../../plugins/apexrest-apex/assets/apexrest-logo.svg) побайтово ідентичний логотипу документації; [іконка поля запиту](../../plugins/apexrest-apex/assets/apexrest-icon.svg) показує символ олівця й лінійки з того самого джерела. Метадані плагіна посилаються на ці SVG через `interface.composerIcon`, `interface.logo` та `interface.logoDark`. Збірки сайту й нативного пакета включають відповідні ресурси.

Наведені нижче англійські й українські SVG-діаграми підтримуються безпосередньо в репозиторії; українські назви файлів закінчуються на `.uk.svg`. Вони використовують нативні векторні форми й системні шрифти без скриптів, зовнішніх ресурсів чи вбудованого HTML. Кожна діаграма має доступні заголовок і опис та `viewBox` для пропорційного масштабування.
