# Стан реалізації

[English](implementation-status.md) | Українська

## Поточний обсяг — 1.0.0, 2026-09-23

APEXREST працює безпосередньо в поточній розмові Codex. Плагін надає 18 MCP-інструментів з обмеженим виводом, 12 спеціалізованих skills, CLI та необов’язкову панель операцій і налаштувань Oracle/APEX. Codex керує завданням, контекстом, моделлю, дозволами й власною співпрацею. Виклик запуску роботи плагіна, контролер сесій моделей, маршрутизація ролей і вибір моделей не входять до продукту.

Випуск зберігає генерацію/експорт/валідацію APEXlang, пошук зафіксованої довідки, обмежені пакети метаданих, транспорти SQLcl CLI/MCP та ORDS, план/застосування розгортання, налаштовані тести, відкриття браузера, стійкі завдання й обмежене читання артефактів. Панель зберігає налаштування проєкту/з’єднань і браузера перевірки.

Розгортання й надалі потребує фактичної ідентичності цілі, дозволу, перевірок drift джерел/цілі, координації та перевіреного backup наявного застосунку. Невідомі результати запису потребують з’ясування. Обов’язкові набори не можуть пройти з порожніми, пропущеними чи заблокованими результатами. Production потребує захищеного зовнішнього схвалення.

## Перевірки

[Поточні локальні докази](evidence/current-session-100-local.json) фіксують точні джерела/збірку та перевірки, виконані для 1.0.0. CLI/stdio MCP, модульні, пакувальні й UI-fixtures підтверджують зазначену локальну поведінку; вони не доводять реальне міркування Codex, виконання Oracle чи відображення desktop, якщо запис явно не містить таких спостережень.

[Історичні підключені докази](evidence/ords-connected.json) підтверджують один дозволений незмінений цикл APEXlang export/import/export з 21 побайтово ідентичним файлом і SQL backup з перевіреною контрольною сумою. Попередні звіти нативного встановлення й компілятора шаблонів Oracle зберігають початкові версії та межі. Цей рефакторинг не повторює тих підключених операцій і не розширює їхніх тверджень.

[Матриця приймання](acceptance.json) розрізняє поточні критерії, вилучені вимоги, наявні докази та відкриті перевірки. Початкова [специфікація збірки](../APEXREST_CODEX_PLUGIN_BUILD_SPEC.md) залишається незмінною як історичні вхідні дані. Історичні JSON-звіти збережено для походження доказів, включно зі звітами видалених функцій; вони не описують 1.0.0.

## Розповсюдження та відкриті перевірки

npm `latest` перевірено як 1.0.0; контрольна сума архіву збігається, чисті локальне/глобальне встановлення успішні. [Запис публікації](evidence/npm-100-publication.json) містить commit джерел та успішний CI на Ubuntu/macOS/Windows.

Версія пакета й нативного плагіна — `1.0.0`. [Примітки до випуску](release-notes.uk.md) відстежують розповсюдження окремо від реалізації та перевірок. Встановлення з реєстру, локальне пакування, джерела GitHub і опублікований сайт — окремі результати.

Ширше покриття платформ нативного хоста, змінені імпорти Oracle, SQL restore, реальні переривання/відновлення, utPLSQL та автентифіковані перевірки застосунку лишаються відкритими там, де їх не охоплюють наявні докази. Вимірювання UTF-8 не є вимірюванням оплачуваних токенів. Дивіться [наступні дії](next-actions.uk.md).
