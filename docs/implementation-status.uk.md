# Стан реалізації

[English](implementation-status.md) | Українська

## Поточний обсяг — 1.1.0, 2026-09-24

APEXREST працює безпосередньо в поточній розмові Codex. Плагін надає 18 MCP-інструментів з обмеженим виводом, 12 спеціалізованих skills, CLI та необов’язкову панель операцій і налаштувань Oracle/APEX. Codex керує завданням, контекстом, моделлю, дозволами й власною співпрацею. Виклик запуску роботи плагіна, контролер сесій моделей, маршрутизація ролей і вибір моделей не входять до продукту.

Випуск зберігає генерацію/експорт/валідацію APEXlang, пошук зафіксованої довідки, обмежені пакети метаданих, транспорти SQLcl CLI/MCP та ORDS, план/застосування розгортання, налаштовані тести, відкриття браузера, стійкі завдання й обмежене читання артефактів. Панель зберігає налаштування проєкту/з’єднань і браузера перевірки.

Розгортання й надалі потребує фактичної ідентичності цілі, дозволу, перевірок drift джерел/цілі, координації та перевіреного backup наявного застосунку. Невідомі результати запису потребують з’ясування. Обов’язкові набори не можуть пройти з порожніми, пропущеними чи заблокованими результатами. Production потребує захищеного зовнішнього схвалення.

## Перевірки

[Каталог компонентів](component-catalog.uk.md) у 1.1.0 додає офлайн-пошук серед 109 сімейств і 138 перевірених компілятором рецептів зі знімка Universal Theme 26.1 Reference, отриманого лише читанням. Один непідтриманий рецепт має явний статус unresolved. [Докази каталогу](evidence/component-catalog-local.json) фіксують покриття джерел, параметри з контекстом, справжній вивід офлайн-компілятора, 181 модульний тест, 42 контрактні тести й 19 пакувальних тестів. Кожен готовий рецепт прив’язаний до hashes scaffold і власних файлів; виконання SQL, імпорт і браузерна перевірка лишаються окремими й у цій роботі не виконувалися.

[Історичні локальні докази 1.0.0](evidence/current-session-100-local.json) фіксують точні джерела/збірку та перевірки, виконані для 1.0.0. CLI/stdio MCP, модульні, пакувальні й UI-fixtures підтверджують зазначену локальну поведінку; вони не доводять реальне міркування Codex, виконання Oracle чи відображення desktop, якщо запис явно не містить таких спостережень.

[Історичні підключені докази](evidence/ords-connected.json) підтверджують один дозволений незмінений цикл APEXlang export/import/export з 21 побайтово ідентичним файлом і SQL backup з перевіреною контрольною сумою. Попередні звіти нативного встановлення й компілятора шаблонів Oracle зберігають початкові версії та межі. Випуск каталогу не повторює тих підключених операцій і не розширює їхніх тверджень.

[Матриця приймання](acceptance.json) розрізняє поточні критерії, вилучені вимоги, наявні докази та відкриті перевірки. Початкова [специфікація збірки](../APEXREST_CODEX_PLUGIN_BUILD_SPEC.md) залишається незмінною як історичні вхідні дані. Історичні JSON-звіти збережено для походження доказів, включно зі звітами видалених функцій; вони не описують 1.1.0.

## Розповсюдження та відкриті перевірки

Ціль стабільного npm-випуску — 1.1.0. Commit, push і публікацію npm дозволено; публікація та перевірка реєстру очікуються у [записі публікації 1.1.0](evidence/npm-110-publication.json). [Історичний запис публікації 1.0.0](evidence/npm-100-publication.json) зберігає перевірену цілісність, чисті встановлення й результати CI Ubuntu/macOS/Windows.

Версія пакета й нативного плагіна — `1.1.0`. Публікація npm відокремлена від вимкненого захищеного publisher артефактів GitHub. [Примітки до випуску](release-notes.uk.md) відстежують розповсюдження окремо від реалізації та перевірок. Встановлення з реєстру, локальне пакування, джерела GitHub і опублікований сайт — окремі результати.

Ширше покриття платформ нативного хоста, змінені імпорти Oracle, SQL restore, реальні переривання/відновлення, utPLSQL та автентифіковані перевірки застосунку лишаються відкритими там, де їх не охоплюють наявні докази. Вимірювання UTF-8 не є вимірюванням оплачуваних токенів. Дивіться [наступні дії](next-actions.uk.md).
