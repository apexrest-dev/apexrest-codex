# 1.0.0 — поточна сесія Codex

[English](release-notes.md) | Українська

## Зміни — 2026-09-23

- Робота з APEX виконується безпосередньо у відкритій розмові Codex користувача з її контекстом, моделлю й дозволами. Скіл роботи більше не викликає API запуску плагіна.
- Видалено власний контролер сесій моделей, маршрутизацію ролей, командні інструменти/скіл, налаштування режиму виконання та пов’язані елементи панелі. Codex керує власною співпрацею.
- Збережено 18 MCP-інструментів і 12 спеціалізованих skills для корисної роботи Oracle/APEX. Панель показує операції, налаштування проєкту/з’єднань і браузера перевірки.
- Збережено APEXlang, SQLcl CLI/MCP, ORDS, обмежену довідку, пакети метаданих, очікування/відновлення завдань, запобіжники розгортання й обов’язкові тести.
- Оновлено англійські/українські README, посібники й сайт; застарілі схеми та скріншоти процесу вилучено. Початкова специфікація збірки лишається незмінною як історичні вхідні дані.

## Перевірка й розповсюдження

[Локальні докази випуску](evidence/current-session-100-local.json) фіксують фактичні джерела, пакет і результати перевірок. Вони не замінюють перевірку живої розмови Codex, Oracle чи застосунку в браузері. Вимірювання пакета/skills/каталогу використовують файли, інструменти й байти UTF-8, а не оплачувані токени.

Версія випуску — `apexrest@1.0.0` без prerelease-суфікса. Публікація npm і синхронізація канонічного GitHub дозволені для цього випуску; метадані реєстру й результати чистого встановлення слід записати після публікації. Зміна версії чи `npm pack` самі по собі не є публікацією. Git-тег, GitHub-випуск і розгортання сайту — окремі дії.

[Стан реалізації](implementation-status.uk.md), [матриця приймання](acceptance.json) та [відкриті перевірки](next-actions.uk.md) відокремлюють реалізований обсяг від історичних і поточних доказів.
