# Панель розробки

[English](panel.md) | Українська

Відкрийте `$apexrest-panel` у Codex для налаштувань проєкту й фактичного стану операцій Oracle/APEX. Скіл викликає `apexrest_panel_open` з абсолютним каталогом застосунку та відкриває повернену приватну локальну URL всередині Codex. Використовуйте проєкт застосунку з `apexrest.json`, а не джерела плагіна чи встановлений кеш. Реалізація триває в [поточній розмові](chat-workflow.uk.md).

```sh
apexrest panel tui --project /absolute/application
apexrest panel status --project /absolute/application --json
apexrest panel open --project /absolute/application --json
```

## Подання

| Подання         | Вміст                                                                                                                                               |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Overview        | Проєкт, зміни Git, фактичний транспорт Oracle та недавні операції                                                                                   |
| APEX operations | Фонові завдання, фактичні вкладені результати, діагностика, артефакти й збережений стан розгортання; компіляція, тести та плани з явним середовищем |
| Settings        | Ідентичність проєкту/середовища, toolchain, обов’язкові набори, браузер перевірки, SQLcl CLI/MCP та Direct Oracle listener / ORDS HTTP(S)           |

Консоль використовує той самий знімок. Обирайте подання цифрами чи стрілками, прокручуйте стрілками вгору/вниз або клавішами сторінок, оновлюйте через `r`, виходьте через `q`. Вебподання оновлюється, поки видиме, і зберігає фокус полів. Зміни транспорту бази стосуються майбутніх операцій; не змінюйте його під час роботи з базою.

## З’єднання й браузер

Прямий доступ Oracle обирає наявне saved connection SQLcl. Відкриття налаштувань завантажує локальні збережені назви без входу в базу; оновлюйте список явно. Наявні відповідності зберігаються за порожнього списку чи зміни транспорту.

ORDS використовує URL схеми та ім’я/пароль наявного облікового запису бази. Вводьте дані лише в приватній локальній панелі або через CLI `--password-file`. MCP-дії з’єднань не приймають паролів. Прямі й ORDS-відповідності зберігаються окремо. Дивіться [налаштування ORDS](ords.uk.md).

`browserMode: codex|external` обирає браузер перевірки сторінок APEX; панель розробки залишається в Codex. Відкриття браузера не є перевіркою поведінки.

## Дії та захист

`apexrest_panel_action` приймає дозволені дії: `preferences`, `sqlcl`, `connection`, `saved-connections`, `cancel-job`, `validate`, `test`, `browser`, `plan`.

```sh
apexrest panel action --project /absolute/application --action '{"kind":"validate"}' --json
```

Панель не надає довіру проєкту чи дозвіл розгортання й не застосовує план безпосередньо. Імпорти використовують [процес розгортання](deployment-safety.uk.md). Фактична помилка завдання лишається помилкою після нормального завершення процесу. Втрачений heartbeat або відповідь зміни можуть залишити `outcome_unknown`; з’ясуйте результат перед повтором. Скасування не відкочує попередніх змін.

Сервер прив’язаний до loopback, перевіряє Host/Origin, видає лише дозволені ресурси й потребує приватного ключа для даних/дій. URL з ключем і файл сесії мають залишатися приватними. Спільне ядро зберігає перевірки довіри, ідентичності цілі, дозволу, backup і drift.

[Поточні локальні докази](evidence/current-session-100-local.json) фіксують перевірки цієї редакції. Попередні звіти панелі/браузера зберігають початкові межі та не є скріншотами чи доказом відображення цього інтерфейсу.
