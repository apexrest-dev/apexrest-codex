# ADR 006: відповідальність за міграції

[English](006-migration-ownership.md) | Українська

Статус: прийнято для локальної бета-версії; інтеграційні твердження потребують доказів.

Змінено [ADR 007](007-clean-apex-deployment.uk.md): службові таблиці не є передумовами; типово використовується стійка локальна історія міграцій.

Адміністратор цілі явно встановлює службові таблиці APEXREST. Назва файла й контрольна сума міграції незмінні; розпочаті/невирішені записи блокують повторення. Повні SQLcl-скрипти виконуються по порядку без розділення PL/SQL чи твердження про відкат DDL. Відновлення застосунку не відновлює даних схеми.
