# ADR 002: довіра до bootstrap

[English](002-bootstrap-trust.md) | Українська

Статус: прийнято для локальної бета-версії; інтеграційні твердження потребують доказів.

Приймайте локальний ZIP і незалежно отриманий SHA-256; необов’язково перевіряйте зовнішній Ed25519 manifest. Фіксуйте URL/хеші постачальників, використовуйте залежності в каталозі користувача й окрему згоду на Oracle/підвищення прав. Ніколи непомітно не використовуйте робочий простір автора й не завантажуйте під час запуску MCP. Віддалені автоматичні канали залишаються вимкненими до появи довірених ключів видавця.
