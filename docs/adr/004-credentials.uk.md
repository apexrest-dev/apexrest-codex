# ADR 004: облікові дані

[English](004-credentials.md) | Українська

Статус: прийнято для локальної бета-версії; інтеграційні твердження потребують доказів.

Використовуйте іменовані посилання на сховище SQLcl без паролів у JSON проєкту чи argv. Зберігайте браузерний стан приватним. Довіра проєкту й grants цілі розміщуються поза репозиторієм; production-ключі/конфігурація належать захищеному runner. Повний дозвіл оболонки залишається поза межею безпеки цієї бібліотеки.
