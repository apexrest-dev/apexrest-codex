# ADR 003: адаптер Oracle

[English](003-oracle-adapter.md) | Українська

Статус: прийнято для локальної бета-версії; інтеграційні твердження потребують доказів.

Перевіряйте можливості справжніх команд SQLcl, зберігайте Oracle APEXlang/MMD, перевіряйте проміжні копії та експортуйте в нові шляхи. Відхиляйте непідтримувані команди/компоненти замість генерації альтернативної DSL. Діагностика відповідної версії розбирається навіть за нульового коду завершення.
