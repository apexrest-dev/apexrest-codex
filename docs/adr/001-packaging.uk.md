# ADR 001: пакування

[English](001-packaging.md) | Українська

Статус: прийнято для локальної бета-версії; інтеграційні твердження потребують доказів.

За зміною користувача від 2026-09-12 єдиний цільовий продукт — Codex. Генеруйте лише нативний пакет `codex-compat` зі спільного запису метаданих, із `.codex-plugin/plugin.json` та обмеженням продукту Codex у marketplace. Колишній portable-пакет більше не випускається; попередні спостереження схеми/хоста залишаються історичними доказами. Інсталятор зберігає сумісність читання старих пакетів для наявних інсталяцій.
