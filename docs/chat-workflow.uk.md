# Робота з APEX у поточній сесії Codex

[English](chat-workflow.md) | Українська

Опишіть зміну Oracle APEX у поточному чаті Codex. [Скіл роботи з APEX](../plugins/apexrest-apex/skills/apexrest-work/SKILL.md) спрямовує реалізацію безпосередньо в цій розмові з її наявним контекстом, моделлю й дозволами. Реєстрація завдання чи виклик запуску плагіна не потрібні.

1. Визначте проєкт застосунку та збережіть запит, обмеження й наданий дозвіл. Повторно використовуйте відому конфігурацію або за потреби викличте `apexrest_project_inspect` із `detail: "summary"`. Налаштовані ідентичності не є перевіркою фактичної цілі.
2. Прочитайте потрібні джерела й відповідні фрагменти довідки, внесіть узгоджені зміни та виконайте доречні перевірки. Повторно використовуйте виявлені налаштування, доки їхні вхідні дані не змінилися.
3. Тривалі операції очікують у межах одного обмеженого MCP-виклику. Завершене завдання може мати помилку: перевірте його фактичний результат і діагностику. Для роботи в черзі чи виконанні очікуйте наявний ID через `apexrest_job_status`; не запускайте роботу повторно лише для отримання результату.
4. Завершуйте дозволені імпорти через [процес розгортання](deployment-safety.uk.md), зберігаючи перевірки ідентичності, backup, drift, координацію й захист невідомих результатів. Наявні обов’язкові набори тестів залишаються чинними.
5. Для видимих змін відкрийте налаштований застосунок через `apexrest_browser_open` і дотримуйтеся [правила браузерної перевірки](testing.uk.md). Фактичні спостереження записуйте окремо від автоматизованих тестів.
6. Повідомте тут зміни, перевірки й обмеження. Уточнення користувача та скасування залишаються в наявній розмові Codex. Відкривайте [панель](panel.uk.md) за потреби чи запитом.

Codex керує власним виконанням і співпрацею. APEXREST надає інструменти Oracle/APEX; він не створює сесій моделей і не обирає моделі. Плагін не має глобального перехоплювача чату чи callback у довільні розмови. Після встановлення або оновлення плагіна може знадобитися нове завдання Codex для оновлення кешованого каталогу skills та інструментів.
