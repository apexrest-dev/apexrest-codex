# Підтримувані версії та докази

[English](versions.md) | Українська

Локальна неопублікована мінорна бета {{version}} орієнтується на Node 24 LTS, SQLcl 26.1.2.132.1334, Java 21 та APEX 26.1+. Операціям APEXlang через ORDS потрібен JDK 21+ із `jdk.compiler`; самого керованого JRE SQLcl недостатньо для Java-засобу. Локально згенерований MMD: 26.1.0+3102. Playwright зафіксовано на 1.63.0 із відповідними ревізіями браузерів.

Ця мінорна версія додає транспорт ORDS HTTP(S), URL і облікові дані бази на рівні плагіна, шляхи імпорту/експорту APEXlang та SQL-копії/відновлення, а також зрозуміліші підписи облікових даних і список збережених з’єднань SQLcl для прямого доступу. Перемикання транспорту зберігає обидві прив’язки. Див. [примітки до випуску](../../docs/release-notes.uk.md).

- macOS arm64: завершено локальні перевірки нативного хоста, клієнтського setup і компілятора.
- Linux x64: зафіксовані клієнтські артефакти й код інсталятора; hosted перевірки якості налаштовано, нативний клієнт та інтеграція Oracle залишаються неперевіреними.
- Windows x64: зафіксовані клієнтські артефакти й PowerShell bootstrap; hosted перевірки якості налаштовано, нативний клієнт та інтеграція Oracle залишаються неперевіреними.
- WSL2: окреме середовище; докази Windows не успадковуються.
- Профіль сумісності Codex: перевірено на 0.154.0.
- Межі продукту: лише Codex desktop і CLI; колишній portable-профіль припинено й не збирається.
- Пісочниця: не підтримується до розгортання й перевірки повного ліцензованого поєднання Oracle/APEX/ORDS.

Наявні [докази ORDS](../../docs/evidence/ords-connected.json) підтверджують один цикл застосунку без змін, 21 побайтово однаковий файл, SQL-копію з перевіркою контрольної суми та відповідний MCP-експорт встановленого плагіна. SQL-відновлення, імпорт зі змінами, додаткові варіанти компонентів/статичних файлів/MMD, відновлення після перерваної відповіді та Windows залишаються неперевіреними; браузерну перевірку застосунку відкладено. Докази зберігають зафіксовані версії збірок і digest коду та не стають новою перевіркою з підключенням після зміни версії.

Сумісність описує спостережену поведінку, а не повне покриття компонентів APEX. Точні хеші постачальників — у запакованому toolchain lock. Майбутні версії бібліотек SQLcl потребують окремої перевірки сумісності засобу ORDS.
