# Підтримувані версії та докази

[English](versions.md) | Українська

Випуск {{version}} орієнтується на Node 24 LTS, SQLcl 26.1.2.132.1334, Java 21 та APEX 26.1+. Локально згенерований MMD: 26.1.0+3102. Playwright зафіксовано на 1.63.0 із відповідними ревізіями браузерів.

- macOS arm64: завершено локальні перевірки нативного хоста, клієнтського setup і компілятора.
- Linux x64: зафіксовані клієнтські артефакти й код інсталятора; hosted перевірки якості налаштовано, нативний клієнт та інтеграція Oracle залишаються неперевіреними.
- Windows x64: зафіксовані клієнтські артефакти й PowerShell bootstrap; hosted перевірки якості налаштовано, нативний клієнт та інтеграція Oracle залишаються неперевіреними.
- WSL2: окреме середовище; докази Windows не успадковуються.
- Профіль сумісності Codex: перевірено на 0.154.0.
- Portable profile: manifest коректний; MCP не виявлено на перевіреній збірці Codex.
- Пісочниця: не підтримується до розгортання й перевірки повного ліцензованого поєднання Oracle/APEX/ORDS.

Сумісність описує спостережену поведінку, а не повне покриття компонентів APEX. Точні хеші постачальників — у запакованому toolchain lock.
