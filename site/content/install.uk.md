# Встановлення в Codex

[English](install.md) | Українська

Встановіть нативний плагін безпосередньо з [репозиторію APEXREST](https://github.com/apexrest-dev/apexrest-codex). Репозиторій містить зібраний пакет плагіна; для використання не потрібно компілювати TypeScript-проєкт.

## 1. Перевірте передумови

Встановіть Node.js 24 LTS і забезпечте доступність `node` у `PATH`. Нативну реєстрацію перевірено з Codex 0.154.0 на macOS arm64. Інші середовища наведено в [матриці підтримки](versions.uk.md).

## 2. Додайте репозиторій і плагін

```sh
codex plugin marketplace add apexrest-dev/apexrest-codex
codex plugin add apexrest-apex@apexrest
```

Перезавантажте Codex і почніть нову задачу для виявлення навичок та інструментів плагіна.

## 3. Налаштуйте доступ Oracle

Дотримуйтеся [посібника початку роботи](../../docs/getting-started.uk.md), щоб перевірити інструментарій і підключити іменоване середовище. Операції Oracle потребують Java 21 і SQLcl 26.1.2; іменовані з’єднання залишаються локальними. Перегляньте ліцензійні умови Oracle перед дозволом керованих завантажень постачальника.

Потім попросіть Codex створити застосунок або оновити визначений застосунок розробки/тестування. Плагін виконає валідацію, планування, імпорт і перевірку дозволеної зміни.

## Збирання з коду чи перегляд файлів випуску

Для розробки плагіна чи відтворюваного пакування клонуйте репозиторій і виконайте:

```sh
npm ci --ignore-scripts
npm run build
npm run site:build
npm run release:dry-run
```

`dist/releases/install-local.txt` містить точні локальні хеші пакетів і команди встановлення Bash/PowerShell. Ці згенеровані артефакти відокремлені від наведеного встановлення через marketplace репозиторію. Підписаний стабільний випуск ще не опубліковано.
