# Випуск {{version}}

[English](releases.md) | Українська

Випуск 1.1.0 додає офлайн-каталог компонентів Universal Theme до роботи в поточній розмові Codex. Плагін зберігає 18 MCP-інструментів і 12 skills для Oracle/APEX; Codex керує розмовою та співпрацею.

## Зміни

- Пошук серед 109 сімейств компонентів і адаптація 138 перевірених компілятором рецептів APEXlang. Один непідтриманий рецепт залишається видимим із явною причиною unresolved.
- Параметри з контекстом, defaults, умови та описи джерел; окремі контракти нативних регіонів, шаблонів звітів/списків, шаблонних компонентів, полів, кнопок і сторінок.
- Селектор `corpus: "components"` у наявних довідкових інструментах і CLI. Чинні IDs довідки Oracle та типове значення `apexlang` зберігають сумісність.
- Комплектний каталог працює офлайн без проєкту чи з’єднання з БД. Отримання джерел, залежності, hashes і справжні докази компілятора відокремлені від розгортання застосунку.

Перегляньте [список компонентів і приклади](https://apex.oracle.com/ut) та [посібник каталогу](../../docs/component-catalog.uk.md). Встановіть через `npm install -g apexrest` або зафіксуйте `apexrest@1.1.0`.

## Докази та розповсюдження

[Докази каталогу](../../docs/evidence/component-catalog-local.json) фіксують 138 офлайн-перевірок компілятора без попереджень, 181 модульний тест, 42 контрактні тести й 19 пакувальних тестів, а також детерміновані перевірки каталогу, документації, плагіна й офлайн-пошуку. Виконання SQL, імпорт, автентифікований браузер і виконання нативною моделлю зберігають окремі [межі перевірки](../../docs/next-actions.uk.md).

[Примітки до випуску](../../docs/release-notes.uk.md) та [запис публікації 1.1.0](../../docs/evidence/npm-110-publication.json) фіксують фактичний результат розповсюдження. Публікація npm, канонічні джерела GitHub, підписані артефакти GitHub і розгортання сайту — окремі результати. Захищений publisher артефактів GitHub залишається вимкненим.

Історичні [публікація 1.0.0](../../docs/evidence/npm-100-publication.json) та [підключені докази Oracle](../../docs/evidence/ords-connected.json) зберігають початкові ідентичності джерел і межі.
