# Випуск {{version}}

[English](releases.md) | Українська

Опубліковано `apexrest@0.5.0` як npm `latest` і вилучено dist-tag `beta`. [Запис публікації](../../docs/evidence/npm-050-stable-publication.json) підтверджує стан реєстру та перевірку встановлення. Встановіть пакет командою `npm install -g apexrest`; попередня `0.5.0-beta.1` залишається доступною за точною версією. Git-тег і GitHub-випуск не входять до цього оновлення.

## Зміни

- Оновлено зафіксовану довідку Oracle APEXlang і навички плагіна за примітками Oracle від 21 вересня та знімком upstream, інтегрованим 22 вересня.
- Охоплено процеси звітів і partial для Media List, Comments та Metric Card; Smart Filters і Search; розширені контракти Cards і Region Display Selector.
- Збережено перевірену базову версію компілятора APEX 26.1 та засоби збереження джерел, валідації й безпеки розгортання.

Повні межі та перевірку описано у [примітках до випуску](../../docs/release-notes.uk.md). Наявні [режими одного агента й команди](../../docs/work-modes.uk.md), [обмежена автоматизація](../../docs/codex-automation.uk.md) та [функції ORDS](../../docs/ords.uk.md) залишаються доступними.

## Наявні перевірки

[Попередні локальні перевірки 0.4](../../docs/evidence/minor-040-local.json) зберігають початкову ідентичність збірки. [Аналіз автоматизації](../../docs/codex-automation.uk.md) відокремлює механічне виконання від міркування Codex. Попередні вимірювання байтів відповідей і нативні/Oracle-звіти зберігають початкові межі; зміна мінорної версії не повторює цих перевірок і не доводить економії оплачуваних токенів.

[Докази з підключенням](../../docs/evidence/ords-connected.json) фіксують один цикл APEXlang без змін із побайтовим збігом усіх 21 файлу, справжню SQL-копію з перевіркою контрольної суми й окремий нативний MCP-експорт із тим самим результатом. [Докази налаштувань](../../docs/evidence/connection-settings-local.json) охоплюють зібрану панель та дії у браузері Codex із синтетичними обліковими даними; [нативне виявлення](../../docs/evidence/connection-settings-native.json) перевіряє справжній локальний список назв SQLcl без входу до бази. Звіти зберігають початкові версії й digest коду та не заявляють нових запусків із підключенням для `0.5.0`.

Імпорт зі змінами, ширші варіанти компонентів/статичних файлів/MMD, SQL-відновлення, відновлення після перерваної відповіді та Windows залишаються неперевіреними. Браузерну перевірку застосунку відкладено. Перевірка готовності стабільного випуску лишається заблокованою.

## Локальні артефакти

Ця збірка створює нативні ZIP, платформні runtime ZIP, bootstrap, контрольні суми, CycloneDX SBOM, походження та ZIP статичного сайту. Runtime ZIP містять JavaScript APEXREST і дозволені повідомлення залежностей; бінарні файли Oracle завантажуються окремо після згоди.

Згенерований `releases/manifest.json` прив’язує версії/контрольні суми інсталятора й нативних артефактів. Повний локальний manifest і звіт готовності — у `dist/releases/`. Непідписані локальні артефакти не є опублікованим GitHub-випуском.

Marketplace репозиторію вже підтримує встановлення з контролю версій. Стабільна кваліфікація окремо потребує доказів нативного хоста кожної платформи, прив’язаних до коду, та решти доказів Oracle, utPLSQL і автентифікованих тестів застосунку. Локальні тести не замінюють цих ширших умов випуску. Dry run ніколи не створює тегів, releases чи npm-пакетів.
