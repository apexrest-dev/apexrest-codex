# Локальний випуск {{version}}

[English](releases.md) | Українська

Ця мінорна бета — локальний неопублікований кандидат. Оновлення версії не створює Git-тега, GitHub-випуску чи публікації npm.

## Зміни

- За замовчуванням працює один агент. Команду потрібно явно увімкнути у Settings; старі збережені типові значення не вважаються таким вибором, а наявні запуски зберігають свій режим.
- Пошук довідки за замовчуванням повертає три результати, підтримує явну пагінацію й не трактує альтернативні типи процесів APEXlang як обов’язкові залежності.
- Обмежено резюме інших агентів, повторно використовується незмінений контекст, завершене виконання інструмента записується один раз.
- MCP повертає стислі резюме з посторінковим доступом до повних деталей зі збереженням результату операції. Автоматичні архіви результатів зберігаються поза вихідним кодом проєкту, повні знімки панелі — у метаданих UI. Локальні перевірки контролюють ліміти обсягу UTF-8.

Повні межі описано у [примітках до випуску](../../docs/release-notes.uk.md), поведінку одного агента й команди — у [налаштуваннях виконання](../../docs/work-modes.uk.md). Наявні [функції ORDS](../../docs/ords.uk.md) залишаються доступними. Менші відповіді не доводять економії оплачуваних токенів.

## Наявні перевірки

[Докази з підключенням](../../docs/evidence/ords-connected.json) фіксують один цикл APEXlang без змін із побайтовим збігом усіх 21 файлу, справжню SQL-копію з перевіркою контрольної суми й окремий нативний MCP-експорт із тим самим результатом. [Докази налаштувань](../../docs/evidence/connection-settings-local.json) охоплюють зібрану панель та дії у браузері Codex із синтетичними обліковими даними; [нативне виявлення](../../docs/evidence/connection-settings-native.json) перевіряє справжній локальний список назв SQLcl без входу до бази. Звіти зберігають початкові версії й digest коду та не заявляють нових запусків із підключенням для цієї мінорної бети.

Імпорт зі змінами, ширші варіанти компонентів/статичних файлів/MMD, SQL-відновлення, відновлення після перерваної відповіді та Windows залишаються неперевіреними. Браузерну перевірку застосунку відкладено. Ця локальна бета не пройшла кваліфікацію стабільного випуску.

## Локальні артефакти

Ця збірка створює нативні ZIP, платформні runtime ZIP, bootstrap, контрольні суми, CycloneDX SBOM, походження та ZIP статичного сайту. Runtime ZIP містять JavaScript APEXREST і дозволені повідомлення залежностей; бінарні файли Oracle завантажуються окремо після згоди.

Згенерований `releases/manifest.json` прив’язує версії/контрольні суми інсталятора й нативних артефактів. Повний локальний manifest і звіт готовності — у `dist/releases/`. Непідписані бета-артефакти не є опублікованим стабільним випуском.

Marketplace репозиторію вже підтримує встановлення з контролю версій. Стабільна кваліфікація окремо потребує доказів нативного хоста кожної платформи, прив’язаних до коду, та решти доказів Oracle, utPLSQL і автентифікованих тестів застосунку. Локальні тести не замінюють цих ширших умов випуску. Dry run ніколи не створює тегів, releases чи npm-пакетів.
