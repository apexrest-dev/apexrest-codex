# Випуск {{version}}

[English](releases.md) | Українська

Випуск 1.0.0 виконує роботу з APEX безпосередньо в поточній розмові Codex. Плагін надає 18 MCP-інструментів і 12 skills для Oracle/APEX. Codex керує розмовою й співпрацею; плагін надає детерміновані операції, налаштування та відновлювані завдання.

## Зміни

- Видалено власні сесії моделей, маршрутизацію ролей, API запуску завдань і відповідні елементи панелі.
- Збережено операції Oracle/APEX, з’єднання SQLcl і ORDS, валідацію, запобіжники розгортання, тести та інструкції браузерної перевірки.
- Збережено обмежений вивід, ліниве завантаження довідки, пакети метаданих та очікування завдання одним викликом.
- Документацію й панель спрощено навколо роботи в поточній сесії.

Точні зміни, перевірку й стан розповсюдження наведено в [примітках до випуску](../../docs/release-notes.uk.md) та [локальних доказах випуску](../../docs/evidence/current-session-100-local.json). Встановіть через `npm install -g apexrest` або зафіксуйте `apexrest@1.0.0`.

## Докази й розповсюдження

Поточні локальні перевірки та історичні нативні/Oracle-звіти мають окремі ідентичності джерел. [Попередні підключені докази](../../docs/evidence/ords-connected.json) підтверджують один незмінений цикл APEXlang і SQL backup з перевіреною контрольною сумою; це не новий підключений запуск 1.0.0. Змінені імпорти, restore, відновлення після втраченої відповіді й ширші платформні/прикладні перевірки зберігають [задокументовані межі](../../docs/next-actions.uk.md).

Встановлення npm, канонічні джерела GitHub, підписані артефакти випуску та розгортання сайту — різні результати. Локальні ZIP, контрольні суми, SBOM і походження не означають публікацію. Фактично завершені дії визначає запис випуску.
