# Порожній застосунок

[English](README.md) | Українська

Це справжній стартовий приклад, згенерований Oracle SQLcl, з початковим `.apex/apexlang.json`. Нові проєкти запускають справжній генератор, а не вигадують метадані з цієї фікстури. Потрібні SQLcl 26.1.2+ і Java 21. Автентифікація залишається типовою для стартового застосунку Oracle. Локальну компіляцію перевірено; розгортання потребує явно налаштованих workspace/schema APEX 26.1+.
